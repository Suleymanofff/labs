Лабораторная работа 15-16. Управление процессами
Вариант 10

Задание:
определить, какие из перечисленных переходов между состояниями процесса являются допустимыми.

Обозначения:
Н - новый процесс;
В - выполняющийся;
Г - готовый;
Б - блокированный;
Б/П - блокированный/приостановленный;
Г/П - готовый/приостановленный;
З - завершающийся.

Переходы варианта 10:
1. В-З - допустим. Выполняющийся процесс может завершиться.
2. В-Н - недопустим. Процесс не возвращается из выполнения в новое состояние.
3. Г-Б - недопустим. Готовый процесс не блокируется, пока не начнет выполняться.
4. Г-Б/П - недопустим. Из готового состояния нет прямого перехода в блокированный/приостановленный.
5. Г-Г/П - допустим. Готовый процесс может быть выгружен из памяти и стать готовым/приостановленным.
6. Г-З - недопустим. Готовый процесс не завершается напрямую, сначала он должен выполняться.
7. Г-Н - недопустим. Переход назад в новое состояние невозможен.
8. Г-В - допустим. Диспетчер выбирает готовый процесс для выполнения.
9. Б-Б/П - допустим. Блокированный процесс может быть приостановлен при свопинге.
10. Б-Г/П - недопустим. При наступлении события для приостановленного процесса используется переход Б/П-Г/П; прямой Б-Г/П не является базовым переходом.

Ответ:
допустимые переходы - 1, 5, 8, 9.
